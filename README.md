# Lead Sniper AI 🚀

Turn Google Maps into a lead generation machine.

This workflow automatically finds local businesses, extracts their data, scrapes their websites, and pulls real emails — all saved directly into Google Sheets.

---

## ⚡ What It Does

- Search Google Maps by keyword
- Collect business details:
  - Name
  - Phone
  - Website
  - Address
  - Rating
- Visit each website automatically
- Extract real emails (filtered, no junk)
- Save everything to Google Sheets

---

## 🔥 Example Use Cases

- SMMA agencies
- Freelancers
- Lead generation businesses
- Cold email outreach
- Local business prospecting

---

## 🧩 How It Works

1. Input a list of search queries
2. Split queries into individual tasks
3. Fetch Google Maps results (pages 1–4)
4. Format and clean data
5. Visit each website
6. Extract emails using regex + filters
7. Save results to Google Sheets

## 🚀 Setup

1. Import workflow into n8n
2. Add your API keys:
   - Serper.dev
   - Google Sheets
3. Update your Google Sheet ID
4. Add your search queries
5. Run workflow

---

## 🧠 Email Filtering Logic

Removes:
- Gmail / Yahoo / AOL
- Image/file links
- Fake/test domains
- Tracking domains

Keeps:
- Real business emails only
